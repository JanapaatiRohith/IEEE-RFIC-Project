# Module 3 — Low-Noise Amplifier (LNA) Design

**Status: Planned — implementation and verification pending.**

## Planned workflow

1. Define the target frequency band, supply voltage, gain, noise figure,
   input/output matching, stability, bandwidth, and power constraints.
2. Select and bias an appropriate IHP SG13G2 device.
3. Develop the initial LNA schematic and ngspice testbench.
4. Simulate DC operating point and AC gain.
5. Evaluate input/output matching, stability, noise figure, bandwidth,
   and power consumption.
6. Tune the design, rerun simulations, and save plots, logs, and measurements.
7. Update the report with final results and limitations.

No completed LNA circuit or verified LNA simulation results are claimed here.
